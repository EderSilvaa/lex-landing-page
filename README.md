# Lex - Legal Tech AI Copilot

Landing page moderna para a startup **Lex**, um assistente de IA integrado ao PJE (Processo Judicial Eletrônico).

## 🚀 Tecnologias

- HTML5 Semântico
- CSS3 Moderno (Variables, Flexbox, Grid, Glassmorphism)
- JavaScript (Vanilla)

## 🎨 Design

O design segue uma estética "Dark Mode" profissional, inspirada em ferramentas de desenvolvimento como Cursor e Linear.
- **Cores**: Void Black (#000000), Deep Blue, Purple e Green.
- **Tipografia**: Inter e JetBrains Mono.
- **Layout**: Bento Grid para funcionalidades.

## 🛠️ Como rodar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.
